# CircleDesign by CircleTel

Landing page concept for CircleDesign, CircleTel's AI-powered growth agency for SMEs.

**Positioning:** We don't get you leads. We get you paying customers.

Open `index.html` in a browser. It's a single static file, with no build step.

Sections: hero with "what problem do you want to solve" ask bar, strike-through positioning band, revenue-leak calculator, the five-stage Customer Engine, you/we split, industries (with compliance moat), CircleTel one-bill advantage, glassmorphism pricing (monthly/yearly), final CTA.
